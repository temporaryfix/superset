## Relay patch warning disproved

The relay Dockerfile already copies `out/json/` before frozen installation. An actual offline **Turbo 2.10.9** `prune @superset/relay --docker` retained the required `@xterm/xterm@6.1.0-beta.302` patch in both the pruned manifest and `out/json/patches/`. The copied patch's SHA256 was `d2c5f1af14560e272784cc7c739c4e24409f942dc81d0746713b8e8777ca38ad`. A separate `COPY patches/` is redundant. The earlier source-only omission classification was corrected; no relay Dockerfile fix was retained. [Reviewed Dockerfile](https://github.com/superset-sh/superset/blob/194c676588ae7955e6abd9990227a84b0f505897/docker/self-host/relay.Dockerfile), [review comment](https://github.com/superset-sh/superset/pull/8237#discussion_r4200663524).

Other bot premises were also contradicted: Garage documents its admin-token environment override; the pinned mobile feature-flag hook takes an optional client, not a boolean default; numeric sandbox host aliases are already rejected; the configured S3 region is already wired. These conclusions do not establish native service acceptance.
